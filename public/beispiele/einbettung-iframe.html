Für Entwickler: So ist der Konfigurator eingebunden

Ein <iframe> genügt – ohne JavaScript auf der einbindenden Seite. Der Konfigurator passt sich der Rahmengröße an (ab 1024 px nebeneinander, darunter gestapelt) und braucht mindestens 640 px Höhe. 

<style>
  .citodomus-frame {
    display: block;
    width: 100%;
    height: clamp(640px, calc(100dvh - 2rem), 820px);
    border: 0;
    border-radius: 16px;
    box-shadow: 0 12px 32px -4px rgba(43, 47, 51, .12);
  }
</style>
<iframe
  class="citodomus-frame"
  src="https://ihre-domain.de/konfigurator/?embed=1"
  title="CITODOMUS 3D-Hauskonfigurator"
  loading="lazy"
  allow="fullscreen; clipboard-write"
></iframe>
ParameterBedeutung
embed=1Einbettungs-Modus (Pflicht)
partner=MAKLER-42 optional: Partner-ID (3–40 Zeichen: A–Z, 0–9, Bindestrich) – wird jeder Anfrage beigefügt
accent=1F5FAD optional: Akzentfarbe als Hex ohne #; zu helle Farben werden automatisch abgedunkelt
#m=one&fa=holz optional: Startkonfiguration im Format des Teilen-Links (z. B. Modell und Fassade)
  • Den fertigen Code mit Partner-ID und Farbe erzeugt der Konfigurator selbst: Schritt 5 → „Für Partner / Webseiten“.
  • Der Webserver des Konfigurators muss die Einbettung erlauben: Header Content-Security-Policy: frame-ancestors 'self' https://ihre-website.de (oder ohne frame-ancestors für beliebige Partnerseiten).
  • HTTPS verwenden – Vollbild und Zwischenablage funktionieren nur in einem sicheren Kontext.
